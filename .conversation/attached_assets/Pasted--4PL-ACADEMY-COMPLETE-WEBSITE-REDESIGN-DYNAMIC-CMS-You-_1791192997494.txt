============================================================
5. ADMIN AUTHENTICATION
============================================================

Do not hardcode an admin username/password in source code.

Use:

ADMIN_EMAIL=
ADMIN_PASSWORD=

from .env during initial setup.

If no admin exists:
- Create the first admin from these environment variables.
- Hash the password securely.
- Store only the hash.
- Never store plaintext passwords.

Allow the admin to change the password after login.

Use:
- Secure authentication
- HTTP-only cookies
- Secure sessions
- Password hashing
- Authorization middleware
- Rate limiting for login

Do not display the password anywhere in the UI.

33. ACAD BOT DATABASE ACCESS
============================================================

ACAD BOT should have READ-ONLY access to approved information.

It must NOT have unrestricted database write access.

Example:

User:
"What is the MBA fee at VGU?"

Process:

Identify university
→ Identify program
→ Query database
→ Return current verified value

If database says:
₹5,00,000

Return:
₹5,00,000

If admin changes it to:
₹5,25,000

ACAD BOT must automatically use:
₹5,25,000
