The `/careers` page is about working with 4PL Academy, distinct from the learner
career-path and industry explorer.

Include a Job Openings section and section-navigation link. When there are no
real openings, show “No open positions right now.” The owner must be able to add
real positions later. Never invent roles or make hiring-now claims without
actual openings.

**Why:** The user initially asked to omit openings, then explicitly changed the
requirement to include a future-editable section and this empty-state message.

**How to apply:** Preserve purpose, work, culture and contact content. A general
careers enquiry must not be described or processed as a student admission
application or as an application for an invented vacancy.
