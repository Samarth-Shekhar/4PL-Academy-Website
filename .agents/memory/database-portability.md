---
name: Database portability
description: Owner-approved PostgreSQL/MySQL support and data-preservation constraints for future switches.
---

The owner chose support for both PostgreSQL and MySQL and explicitly required that “all data should be preserved” when moving to MySQL.

**Why:** database flexibility must not cost existing Academy content, leads, administrator profiles, or their relationships.

**How to apply:** a future real database move needs an explicitly identified target, a backup, and verified copying of records and relationships. A request for dialect configuration is not permission to erase the original database or run destructive schema changes on an existing target.
