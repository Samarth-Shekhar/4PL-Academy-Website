## Source and resolution disclosure

Student Grad returned blank reference captures and a failed content fetch, so this
is an image-led interpretation of the user's requested program direction, not a
verified pixel-for-pixel copy.

The original generated artwork is 1024×1024. The 3840×2160 versions are cropped and
upscaled 4K-sized exports, not native 4K photography. 1920px and 960px versions and
480px thumbnails avoid downloading large assets on small screens.

Artwork source metadata explicitly identifies generated concept imagery rather
than verified photos of a particular institution, participant or event.
